# Powering Through

*A Network Analysis of the US Western Interconnect*

Graph-theoretic analysis of the US Western Interconnect power grid: degree distribution, scale-free and small-world properties, and cascading failure simulation. Built with NetworkX, Plotly, and Quarto.

---

## Read Online

**[https://altustd.github.io/us-power-grid-network/](https://altustd.github.io/us-power-grid-network/)**

---

## Run Locally

```bash
pixi install
pixi run render      # HTML → docs/
pixi run render-pdf  # PDF → docs/
pixi run preview     # live preview
```

## Tech Stack

Quarto · NetworkX · Plotly · pixi
